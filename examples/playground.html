参数实验台

左边改参数，右边的滑条立刻生效。调好之后把下面的 JSON 抄进 Scrollpeak.init({...})。

怎么用这个页面

把指针移到页面最右侧的滑条上，峰值会跟随指针；离开滑条后，峰值回到跟随滚动进度。

改左边的任意参数，滑条会立即重建，不需要刷新。

peakGain：峰值横向放大

决定峰值条最长能到静止宽度的几倍。调大更醒目，调太大在窄屏上会顶到正文。

peakGainY：峰值纵向加粗

大于 0 时峰值条同时变粗，形成胶囊感。这就是「已处理版」的主要手法。

sigma 系列：四条衰减曲线

峰形由四条高斯曲线决定，每条都分「闲置 / 触发」两个取值：横向的 sigmaIdle / sigmaActive 管放大与透明度，纵向的 sigmaYIdle / sigmaYActive 管加粗范围。

四个都默认跟随基准值 sigma；sigmaY 是「一次设两个纵向值」的简写。

两个状态之间用归一化强度混合：闲置时恰好取 *Idle，完全触发时恰好取 *Active，中间平滑插值。

sigmaYIdle / sigmaYActive：加粗的上下范围

单独控制「峰值上下各多少根条形会被加粗」，与横向解耦。

调小只有紧邻的一两根变粗，胶囊更锐利；调大则上下形成一片平缓的隆起。

把闲置值调小、触发值调大，就能做出「平时收着、悬停后摊开」的效果。

peakGainYIdle：未触发时的保底加粗

未触发时强度只有 idle（默认 0.3），纵向加粗只有 peakGainY × idle ≈ 36%，所以峰几乎看不出来。

peakGainYIdle 是一份与触发强度无关的恒定加粗量，专门用来让未触发时也能看出峰在哪。

它只影响粗细，不影响长度与透明度；想让长度也一起变明显，调大 idle。

windowSigma：每帧算多少根

每帧只重算峰值附近 ±windowSigma × max(四个 sigma) 根条形，这是性能开关。

调得比 3 还小时，峰的两侧可能被截断，出现硬边。

barWidth / barHeight / barGap

条形静止宽度、高度与间距。三者共同决定轨道总高：N × barHeight + (N−1) × barGap。

hitWidth：触发区宽度

从页面右边缘往左算的感应宽度。调大更容易触发，但也更容易被误触发。

padY：滑槽上下余量

触发范围在条形上下各留出的余量。它只影响触发区，不影响条形本身的位置。

idle：未触发时的强度

指针不在滑条上时峰值的强度。0 表示完全躺平，1 表示与触发时一样醒目。

peakRing：峰值描边

给峰值条描一圈细边。开启后组件会自动给条形区留出空隙，避免描边被裁掉。

quantScale / quantOpacity

把连续的缩放与透明度量化成整数再比较，只有跨过一级才写一次样式。

调大更细腻但写入更频繁，调小更省但可能出现台阶感。

layer：合成层策略

container 只提升轨道一个图层，条目多时最省内存；bar 每根条形一个图层，条目少时最顺滑。
