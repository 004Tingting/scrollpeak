初始化参数：Scrollpeak.init({ peakStyle: 'plain' })
对照页：已处理版（bold） · 参数实验台

这是什么

一条贴在页面右侧的滑动指示条：条形右对齐、从右向左生长，整条轨道上只有一个峰。

鼠标不在轨道上时，峰的位置对应页面滚动进度；鼠标进入轨道后，峰改为跟随指针。

未处理版的样子

所有条形静止宽度一致，宽度差异只来自峰值本身，所以永远不会出现「假峰」。

峰值按高斯曲线衰减，半宽 σ 以「根」为单位，默认 1.8。

触发范围

可触发的竖直范围只覆盖第一根到最后一根条形、上下各留 22px 余量，不是整页高度。

所以指针必须真的移到轨道附近才会触发，不会在页面右侧随便划一下就弹出提示卡。

明暗自适应

组件读取页面背景亮度：浅色页面用灰黑条形，深色页面用灰白条形，提示卡配色同步。

右上角按钮可以切换，滑条颜色会立刻跟着变。

提示卡

触发后会在轨道左侧弹出一张只含标题的提示卡，长标题单行省略号截断。

同时左侧正文里对应的标题会变色高亮，便于确认当前位置。

点击跳转

在轨道任意位置点击，会平滑滚动到对应的章节。

光标悬停时显示手型指针，提示这里可以点。

峰值怎么算

峰值位置是一个 0–1 的连续值，乘以「条形数 − 1」得到连续的条形序号。

每根条形的强度取高斯函数在该处的值，再分别映射到横向缩放与透明度。

为什么不用整页高度取比例

条形只占滑槽中间一段，上下各有留白。按滑槽高度取比例会让指针与条形上下错位。

正确做法是用条形间距换算：idx = (clientY − railTop − firstCenter) / step。

性能取向

逐帧只写 transform 与 opacity，不碰 width / left / background-color。

阻尼收敛后 rAF 循环直接退出，页面静止时主线程占用归零。

窗口化更新

每帧只重算峰值附近 ±windowSigma × max(四个 sigma) 根条形，与文档长度无关。

离开窗口的条形会被复位成静止状态，因此不会留下残影。

合成层

整条轨道只提升一个合成层，不给每根条形加 will-change。

文档有 1000 个章节时，这也是 1 个图层和 1000 个图层的区别。

怎么用到自己页面

给内容容器加 data-scrollpeak，引入 dist/scrollpeak.min.js，调用 Scrollpeak.init() 即可。

条目文案默认取容器子元素里的标题，也可以用 data-sp-title 单独覆盖。
