Scrollpeak · 已处理版

峰值额外加粗并描一圈细边，扫一眼就能定位。适合条目多、需要快速定位的目录页。

初始化参数：Scrollpeak.init({ peakStyle: 'bold' })
bold 预设 = peakGain: 5 · peakGainY: 1.2 · sigma: 1.6 · peakRing: true
对照页：未处理版（plain） · 参数实验台

「已处理」处理了什么

峰值条在横向放大的同时纵向也加粗，从一根细线变成一颗饱满的胶囊。

再加一圈 1px 描边，与背景形成明确边界，深色页面上尤其明显。

加粗：纯 transform，零额外成本

纵向加粗由 scaleY 完成，和横向的 scaleX 写在同一条 transform 里。

不改变元素尺寸，因此不触发重排，也不增加每帧的样式写入次数。

描边：一个覆盖元素

描边不是每根条形一个伪元素，而是整条轨道共用一个覆盖元素，逐帧挪到峰值条上。

代价是每帧一次微型尺寸写入；因为轨道本身带 contain: layout，影响范围被限制在轨道内部。

描边为什么不会被裁掉

条形区带 overflow: hidden，描边会超出条形边界 2px。

开启 peakRing 时组件会自动给条形区留出这段空隙，把条形整体左移，描边就不会被切。

峰值更窄

bold 预设把 sigma 从 1.8 收到 1.6，峰更尖，相邻条形的过渡更短。

配合更大的 peakGain，峰与静止条形的对比度明显拉开。

什么时候该用它

章节多、标题长、用户需要「一眼看出现在在哪」时，加粗描边的收益最大。

如果是阅读型长文、希望滑条尽量不抢视线，用未处理版更合适。

两版之间可以随时切

右上角按钮调用的就是 sp.setOptions({ peakStyle: 'plain' })。

切换预设会整体重算参数，预设带进来的 peakGain / peakGainY / peakRing 会干净地还原。

只想要其中一项

可以关掉描边只保留加粗：{ peakGainY: 1.2, peakRing: false }。

也可以只要描边：{ peakRing: true, peakGainY: 0 }。

描边的颜色

默认按明暗主题自动取色，也可以用 peakRingColor 指定任意 CSS 颜色。

线宽与空隙分别是 peakRingWidth 与 peakRingGap。

发光（可选）

打开 peakGlow 会给峰值条加一层柔和外发光，随 transform 一起缩放，不额外增加写入。

深色页面上发光比描边更含蓄，可以两者取其一。

动效强度

加粗与描边的强度都跟着触发强度 t 走：未触发时几乎看不出来，指针进入后才完全展开。

想让峰值在未触发时也保持醒目，调高 idle 即可。

怎么用到自己页面

与未处理版完全一致，只是初始化时多传一个 peakStyle: 'bold'。

所有参数都能在 playground.html 里实时调，调好之后把参数抄走即可。
